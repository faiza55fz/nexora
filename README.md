# Nexora Marketplace

Premium Indian e-commerce UI for B2C shoppers, B2B buyers, third-party sellers and platform admins.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Surfaces

- Storefront: `/` `/products` `/products/[id]` `/cart` `/checkout` `/track/[id]` `/account/*` `/compare` `/deals`
- B2B: `/b2b` (bulk, RFQ, negotiation, POs, invoices)
- Seller: `/seller` and `/seller/register`
- Admin: `/admin`

Toggle **Personal / Business** in the header and light/dark from the sun/moon control.
